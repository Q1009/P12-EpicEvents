## [1.0.0] - 2026-11-09

### Added
- Initial release of EpicEvents CRM application
- MVC architecture with Textual CLI framework
- JWT authentication system with RSA keys
- RBAC permission system with three roles (ADMIN, SALES, SUPPORT)
- Customer management (CRUD)
- Contract management (CRUD with status tracking)
- Event management (CRUD with support assignment)
- Collaborator management (CRUD for ADMIN role)
- Database seeding with sample data (6 collaborators, 10 customers, 8 contracts, 5 events)
- Sentry integration for error tracking
- Comprehensive test suite
